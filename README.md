# 🍕 Pizza-Track — Sistema de Gestión de Pedidos

Proyecto de la asignatura **Estructura de Datos** (PREICA260).
Simula la gestión de pedidos de una pizzería con **Undo/Redo** usando pilas manuales con listas ligadas en Java.

## Archivos
- `Pizza.java` → Modelo de datos
- `PilaManual.java` → Pila manual con lista ligada
- `GestionPedidos.java` → Controlador principal + menú

## Ejecutar
```bash
javac Pizza.java PilaManual.java GestionPedidos.java
java GestionPedidos
```
